# Collaboration & Outreach Ideas

## 1. Modular Brewing Calculator Library
Combine rwilson4's Python unit-parsing, chrisgilmerproj's BrewDay formulas, and M0N0S0DIUM's Next.js calculator framework into a shared `brew-calc` package. Standardize on JSON recipe schema.

## 2. Open Fermentation Data Format
Draft a common JSON/CSV schema for fermentation sensor data (temp, airlock bubbles, gravity over time) shared across BrewBench, BrewMonitor, BrewSource-RPi, and iSpindel tools.

## 3. Pitch Rate + Starter Recommendation Engine
Build a shared calculation core (Mr. Malty + MoreBeer) usable by both shanehead/brewski (Rust/Tauri) and M0N0S0DIUM's web app. Add viability estimation.

## 4. Brew Journal REST API
Expose jsled/brew-journal as read-only API so third-party tools can push/pull batch data. Creates ecosystem around shared journal.

## 5. Unified Hardware Firmware
ESP32/ESP8266 firmware supporting BOTH BrewBench REST API AND BierBot-Bricks web dashboard. Unite Arduino + ESP8266 communities.

## 6. Shared Water Chemistry Database
Merge rwilson4's targeting with zrrbite's mineral recipes (TWW, Lotus, Hendon). City-level defaults + CLI: "what salts for my target profile?"

## 7. Cross-Craft Fermentation Science Site
Leverage yeastlab's beer+sourdough+coffee approach for documentation site. HomebrewCon talks, Reddit outreach (r/homebrewing, r/Sourdough).

## 8. Homebrewing Hackathon
Virtual "BrewHack" weekend — 48hr integrated tool builds. Prizes: sensor setups, hardware bundles. Partner with BrewPi / GotCloudBeer.
